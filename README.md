# 📚 Book Easer

**Book Easer** is a Next.js application designed to streamline appointment bookings. It includes three main pages:

- **Home** – The landing page for users
- **Booking** – A form where clients can schedule their appointments
- **Dashboard** – A staff-only page to view and confirm client bookings

---

## 🚀 Features

- Simple and intuitive booking system
- Staff dashboard to manage and confirm appointments
- Built with Next.js for fast performance and SEO optimization
- Responsive design for all devices
